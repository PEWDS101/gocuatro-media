# gocuatro-media

Video files for GoCuatro's social posts, nothing else.

This repo is public for one reason: the Instagram Graph API will not accept a
file upload. It takes a public HTTPS URL and fetches the video itself, so the
file has to be reachable before it can be published.

Served via jsDelivr:

    https://cdn.jsdelivr.net/gh/PEWDS101/gocuatro-media@main/reels/<file>.mp4

No source, no config, no secrets. The site repo is private and separate.
